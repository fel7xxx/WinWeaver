# Проверка перед релизом

Автоматическая проверка: `powershell -NoProfile -File scripts/verify.ps1` из корня репозитория.
Она проверяет синтаксис PowerShell, успешный/ошибочный откат на заглушках и сборку net48/net8.0. Системные настройки не применяются.

## Ручная проверка в Windows-ВМ со снимком

- Установка из папки публикации; запуск установленной копии после удаления исходной папки.
- Обновление установленной копии, удаление, работа ярлыков.
- Ошибка доступа к каталогу данных: запуск должен блокироваться.
- Применение, частичная ошибка, отмена активной/ожидающей задачи, повторный запуск и откат.
- Windows 10/11, масштаб 100/150/200%, клавиатурная навигация, увеличенный текст.
- Все разделы на русском и английском; проверить переносы новых переведённых подписей.
- Обновление с последнего опубликованного релиза без потери настроек и истории отката.
- Отключённый интернет, недоступный GitHub, закрытие во время операции.

## Ограничения

net8.0 предназначен для демо/разработки; реальный PowerShell-движок включён в net48.
Распространяйте весь каталог публикации, не один EXE.
Проверка сборки не доказывает корректность системных твиков. Ошибки внешних утилит и команды с явным SilentlyContinue требуют отдельного аудита.
Установщик пока не обеспечивает транзакционное обновление/откат файлов при ошибке копирования.
Отмена не гарантирует автоматическое восстановление уже изменённых параметров.
