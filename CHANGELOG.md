## [1.0.2] — 2026-10-11

### Изменено / Changed
- Интерфейс полностью переведён на Avalonia 11.2.3 (Skia) вместо GDI+/User32; внешний вид, страницы, диалоги и PowerShell-движок сохранены. Подробности — `docs/AVALONIA-PORT.md`.
- Новая навигация: верхнее меню «Главная · Система · Инструменты · Настройки», вкладки разделов со счётчиками.
- Новая страница «Рекомендованные» — всё, что программа советует для этого ПК, с индексом по разделам.
- Панель подробностей у настроек: зачем, кому может не подойти, риск, перезагрузка, откат.
- Поиск и команды по `Ctrl+K`.
- Программа распространяется папкой (WinWeaver.exe + библиотеки Avalonia/Skia), а не одним exe.
- Структура репозитория: `WinWeaver/` (App, Compat, Assets, Resources), `WinWeaver.sln`; CI — workflow `verify.yml` (`scripts/verify.ps1`).

### Исправлено / Fixed
- Английский перевод встроен в сборку (раньше загрузчик мог его не найти); добавлены недостающие переводы навигации, панели подробностей и диалогов.
- История замечает изменения только регистра букв и типа значения в реестре.
- `KeepReg` больше не теряет команду отката, не связанную с реестром.
- Ошибки удаления ключей реестра и восстановления служб больше не отмечают откат как успешный.
- При частичной ошибке сохраняется признак перезапуска Проводника.
- Выбор DNS проверяет индекс провайдера и передаёт ошибки установки.
- Быстрый запуск проверяет код возврата `powercfg` перед записью в реестр.
- Главная, подтверждение автонастройки и «История» больше не обещают, что откатить можно любое действие.

## [1.0.1] — 2026-10-09

### Изменено / Changed
- Главная: новый баннер — под версией Windows кликабельные чипы «Уровень» и «Изменений»; характеристики ПК плитками 2×2 (длинные названия CPU/GPU переносятся, а не обрезаются); «Глубина» у карточек уровней — компактной строкой внизу, на одной высоте у всех карточек; у заголовка автонастройки подсказка «Любое изменение можно откатить».
- Окно автонастройки компактнее: ниже баннер и отступы, плотнее список шагов и переключатели — не закрывает всё окно программы.
- Плавность: анимации и прокрутка считают время по высокоточным часам (системное время шло шагами ~15,6 мс — отсюда рывки); шиммеры и спиннеры двигаются равномерно независимо от частоты кадров.
- Прокрутка: реагирует на колёсико сразу, доводка быстрее (~45 мс), шаг учитывает масштаб экрана и настройку Windows «строк за щелчок».
- Запуск новой версии предлагает обновить установленную копию в Program Files.

### Исправлено / Fixed
- Файл `WinWeaver_lag.txt` больше не создаётся на рабочем столе (журнал подвисаний пишется только при `WW_LAG=1` в `C:\ProgramData\WinWeaver`); старый файл с рабочего стола удаляется при запуске.
- Уведомление о задаче («Читаю разделы», автонастройка и т. п.) больше не всплывает поверх других приложений, когда WinWeaver в фоне.
- Прокрутка: быстрые движения колёсиком вверх-вниз больше не гасят друг друга; открывшаяся полоса страницы рисуется вместе с карточками в том же кадре; карточки не мигают подсветкой, проезжая под курсором.
- Анимации: `Tween.Snap()` не останавливал идущую анимацию — прогресс-бары и кольца «отскакивали»; переключатели на общем таймере анимаций, без мигания цвета ползунка; окно автонастройки не мигает перед появлением; уведомление и экран загрузки не «перепрыгивают» анимацию при подвисании.
- Интерфейс: «залипшая» подсветка кнопок и карточек; курсор-рука на сердечке и баннере обновления в боковой панели.
- Переключатель или выбор, у которых не сработала установка, показывает реальное состояние, а ошибка выводится отдельно.
- Утечки GDI: шрифты в каждой отрисовке, области обрезки (`g.Clip`), кисть в «Восстановлении», регион меню.
- Шиммер-заглушки пропадали после ~25 дней аптайма.
- Обновление поверх установленной копии не падает, если она сейчас запущена (старый exe переименовывается).
- Повторный запуск во время загрузки больше не ломает «показать уже открытое окно».
- Ответы движка: ключи хэш-таблиц PowerShell читаются без учёта регистра.

## [1.0.0] — 2026

Первый публичный выпуск. / First public release.

### Главное
- **Автонастройка в один клик** — три уровня: «Базовая» (приватность без удаления программ), «Оптимальная» (чистая и быстрая Windows на каждый день), «Максимальная» (максимум FPS). Перед изменениями создаётся точка восстановления.
- **Предпросмотр и выбор шагов**: перед запуском видно, что изменится, любой шаг можно выключить.
- **Стиль WeavOS — по желанию**: 4 варианта обоев в 4K («Ледяной шёлк», «Графит», «Сияние», «Серебро»), название WeavOS в «О компьютере», имя компьютера и пароль входа — на отдельном шаге, всё можно пропустить.
- **История и откат**: каждое изменение записывается и отменяется отдельно или группой.
- **«Что вернула Windows»**: после крупных обновлений программа замечает, какие настройки Windows включила обратно, и предлагает применить их заново.
- **Экспертный режим**: настройки, которые ослабляют защиту (полное отключение Defender, VBS/HVCI, Spectre, «Не спрашивать» в UAC, службы, сжатие памяти, расшифровка BitLocker), скрыты, пока режим не включён.
- **Edge удаляется официальным деинсталлятором** и только после установки выбранного браузера; WebView2 остаётся.
- **Профили настроек**: экспорт и импорт в .json (только значения переключателей, без кода) с показом отличий перед применением.
- **Командная строка**: `/apply`, `/uninstall`, `/version`, `/help`.
- **Сообщить об ошибке** прямо из программы: форма на GitHub с подставленной версией и Windows, сведения для разработчика с замаскированными именами.
- **Проверка новых версий** на GitHub — только уведомление, ничего не скачивается.

### Интерфейс
- Новый дизайн: тёмно-серый с ледяным голубым акцентом, плавные анимации.
- Окно первого запуска: язык, установка в Program Files или запуск без установки, автозапуск, уведомления о версиях.
- Русский и английский языки: по умолчанию как в Windows, переключаются в «Настройках». Переводы — таблицы `lang/*.tsv`.
- Все разделы читают состояние сами — сразу при открытии и в фоне после запуска.

### Установка и удаление
- Установка в `C:\Program Files\WinWeaver` с ярлыком в Пуске и записью в «Установленных приложениях».
- Полное удаление: задачи планировщика, автозапуск, ярлыки, схема питания, файлы программы и данные; по желанию — сначала откат всех изменений.

### Безопасность
- Папка данных доступна для записи только администраторам и SYSTEM.
- История хранит данные, а не код — при откате ничего не выполняется из файла.
- Установщики проверяются по цифровой подписи или закреплённому SHA-256 и скачиваются в защищённую папку.
- Задача автозапуска создаётся только для копии в Program Files.
